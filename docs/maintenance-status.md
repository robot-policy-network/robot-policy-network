# Project status

**Status: maintenance hiatus**

This project is not planned to receive active feature development for the foreseeable future. The current release is preserved as a public reference implementation and as a record of the Arc mainnet deployment evidence available at the time of release.

## What this means

- No new protocol features, marketplace functionality, or production integrations are currently scheduled.
- The deployed contract and published repository remain available for independent inspection.
- The live deployment is not a guarantee of ongoing service availability, support, funding, or future compatibility.
- The repository should not be interpreted as an active commercial product or a commitment to continue development.
- Users must independently verify the live chain state, contract behavior, website availability, and transaction details before interacting.

## Security reports

Security reports may still be submitted privately according to [`SECURITY.md`](../SECURITY.md). A report may be acknowledged or documented, but there is no commitment to provide a fix or a response within a particular timeframe during this maintenance hiatus.

## Scope boundary

The project does not claim that general-purpose USDC escrow, a robot-policy marketplace, or any other future extension is deployed. See [`limitations.md`](limitations.md) and [`deployment.md`](deployment.md) for the current evidence and limitations.
