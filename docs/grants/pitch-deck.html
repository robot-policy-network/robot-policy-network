The Problem

How does a machine get paid for work
without a human trusting the machine's word?

Agent-payment tools: the human still decides.
Escrow/oracle designs: an unverified score moves money.
Human review: does not scale.

We need: a payment triggered by proof of work, not by a claim of work.

Evaluation Is Execution-Anchored

Agents submit structured action plans for tasks sliced from real robot trajectories (DROID dataset).

A deterministic simulator executes each plan across seeded perturbations.

A plan that does not run scores zero.

67 missions · 2.5M atomic actions · 100% mode:sim · no LLM grading
